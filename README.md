# 《冰人奇境》❄️

一款原创主角与原创场景的五关横版跳跃冒险。无需安装或联网，双击 `index.html` 即可游玩。

## 操作

- `←` / `→` 或 `A` / `D`：移动
- `空格` / `W` / `↑`：跳跃
- `X`：发射冰球
- `E`：互动（镜湖遗迹中靠近镜台时显出银桥）
- `Esc` / `P`：暂停；`R`：重玩本关
- 手机和平板可使用画面下方的大按钮

没有倒计时。跌落或碰到危险后会在本关出生点或已触发的存档点复活。

## 五关

| 关卡 | 关卡机制 | 专属收集物 |
|---|---|---|
| 冰晶村 | 滚雪球怪 | 霜花徽记 |
| 风雪松林 | 上升气流柱 | 风铃核心 |
| 熔岩矿坑 | 往返矿车平台 | 玄冰矿石 |
| 镜湖遗迹 | 显隐镜面平台与滑冰地面 | 月镜碎片 |
| 极光城堡 | 冰球冻结 Boss | 极光之心 |

每关只有一种专属收集物，五种物品的 ID 与类型都不重复。

## 验证

在本目录运行：

```bash
node tools/test-core.js
node tools/test-level-validation.js
node tools/validate-levels.js
```

关卡验证器用实际游戏物理检查全部 22 段主路线平台跳跃，并校验五关机关和收集物唯一性。
