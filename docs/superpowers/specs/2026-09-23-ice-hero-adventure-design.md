# 《冰人奇境》设计规格

## 目标

制作一款原创、儿童友好的经典横版跳跃闯关游戏。主角是冰人，包含五个风格和机制不同的关卡；所有主路线跳跃必须能用游戏实际物理参数完成。

## 体验与平台

- 双击 `index.html` 可在浏览器游玩，无构建步骤、无外部依赖、无网络资源。
- 桌面支持方向键 / A、D 移动，空格 / W / 上方向键跳跃，X 发射冰球；手机显示大尺寸触控按钮。
- 不设倒计时；失败后在本关出生点或存档点复活。跳跃带输入缓冲和离台宽限，避免操作边缘误差导致挫败。
- 视觉风格为明快的原创卡通冰雪冒险，不使用马里奥角色、商标或素材。

## 五关设计

| 关卡 | 主题与独有机制 | 唯一收集物 |
|---|---|---|
| 冰晶村 | 教学关；宽平台、短缺口、滚雪球怪 | 霜花徽记 |
| 风雪松林 | 上升气流柱与风铃平台 | 风铃核心 |
| 熔岩矿坑 | 运输矿车作为移动平台，熔岩仅作危险区 | 玄冰矿石 |
| 镜湖遗迹 | 低摩擦冰面与镜面开关显隐平台 | 月镜碎片 |
| 极光城堡 | 多段平台 Boss 战；冰球命中冻结 Boss 并创造输出窗口 | 极光之心 |

各关恰好设置一个专属收集物；收集物 ID 和类型互不重复。不放置可重复刷取的金币、蘑菇或同款道具。平台与基础地形可以复用基础碰撞规则，但每关的主题机关、主要危险和目标物各不相同。

## 技术结构

- `game-core.js`：无 DOM 的关卡数据、玩家物理、碰撞、存档点、机关和 Boss 状态；同时支持浏览器和 Node。
- `index.html`：Canvas 绘制、菜单/HUD、键盘与触屏输入、响应式布局。
- `tools/test-core.js`：核心物理和规则的可重复检查。
- `tools/validate-levels.js`：关卡结构、物品唯一性、主路线跳跃可达性检查。
- `README.md`：玩法、操作、启动和验证说明。

## 防止不可达跳跃

关卡以明确的平台段和主路线平台 ID 表达。验证器使用与游戏相同的角色尺寸、重力、跳跃速度、水平速度和单向平台落地规则，逐对模拟主路线平台间的跳跃；任一段不能落到目标平台即失败。几何规则另设安全余量：主路线缺口不得超过实测安全水平距离的 70%，平台高度变化也受限。核心物理加入 120ms 起跳缓冲和 100ms 边缘宽限。存档点放在每关主要挑战前。

## 验收

1. 五关均可开始、通关并解锁下一关；刷新后保留解锁进度。
2. 五个专属物品各出现一次，ID 和类型均不重复。
3. `node tools/test-core.js` 与 `node tools/validate-levels.js` 全部通过；实际物理模拟覆盖每一段主路线跳跃。
4. 浏览器可正常开始、移动、跳跃、暂停/重开、触屏操作，且无 JavaScript 错误。
5. 桌面与窄屏下 HUD 和触控按钮不遮挡主要游戏画面。
