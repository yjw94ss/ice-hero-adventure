# 《冰人奇境》实现计划

> **面向 AI 代理的工作者：** 按顺序执行每项任务。先写行为检查并看到预期失败，再实现最小代码。

**目标：** 在 `games/ice_hero_adventure/` 构建一款五关原创横版冰人冒险游戏，并通过实际物理验证所有主路线跳跃可达。

**架构：** `game-core.js` 保存关卡和纯游戏逻辑，可由浏览器及 Node 共用；`index.html` 只负责绘制、界面和输入。Node 工具验证物品唯一性、关卡配置和基于同一物理引擎的主路线平台跳跃。

**技术栈：** 原生 HTML/CSS/Canvas/JavaScript；Node 内置 `assert`，无 npm 依赖。

**规格：** `docs/superpowers/specs/2026-09-23-ice-hero-adventure-design.md`

## 全局约束

- 五个手工设计关卡；各关专属收集物 ID/类型互不重复。
- `index.html` 双击可玩；不依赖外部素材或网络。
- 五关主路线的每一跳由真实游戏物理模拟验证。
- 桌面键盘和触屏均可操作；无倒计时，关卡有检查点。

## 文件职责

- 创建 `game-core.js`：关卡数据、游戏状态、物理步进和公共校验/模拟 API。
- 创建 `tools/test-core.js`：纯 Node 行为检查，覆盖关卡数、物品唯一、跳跃和复活规则。
- 创建 `tools/validate-levels.js`：读取核心关卡，检查主路线和跳跃安全余量。
- 创建 `index.html`：Canvas 游戏画面、卡通 UI、输入、菜单、进度。
- 创建 `README.md`：启动、操作、关卡说明、验证命令。
- 修改 `../README.md`：登记新游戏。
